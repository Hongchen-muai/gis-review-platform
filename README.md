# 地理信息系统导论专业课复习平台 🗺️

> **专为中国科学院大学 / 中国科学院地理科学与资源研究所（中科院地理所）839 地理信息系统考研深度定制**  
> 亦全面适配武汉大学、南京师范大学、北京师范大学、华东师范大学、中国地质大学等名校GIS考研复习。

---

## 🌟 核心特性与平台功能

1. **🌐 全景交互式思维导图（Mind Map Tree）**
   - 宏观覆盖 4 大知识板块、18 个核心章节、80+ 个知识小节与数百个细分考点；
   - 支持任意层级节点自由折叠、展开与缩放；
   - 点击任意节点在右侧抽屉无刷新弹出该考点的标准定义、大题解析与原书出处。

2. **🏛️ 中科院地理所 839 历年真题与名校高频大题库**
   - 紧密契合中科院 839 最新大纲（**纯 GIS，无遥感**）；
   - 收录 2013-2023 年中科院 839 历年经典真题（如 2020 井盖建库综合大题、2013 栅格矢量化大题、头文件作用、四叉树压缩、克里金BLUE无偏估计等）；
   - 配套标准五步得分法答题范式（定义 → 数据结构/数理模型 → 算法步骤 → 优缺点评价 → 现实应用案例）。

3. **📚 知识点 100% 溯源教材原书出处**
   - 严格对应 Kang-tsung Chang《地理信息系统导论（原著第8版，陈健飞等译）》全书正文页码；
   - 考点卡片与手册中逐条标明 `📚 教材出处：第X章 X.X节，Pxx-xx`，方便随时翻书深读。

4. **📐 印刷级数理公式优雅渲染（MathJax 3）**
   - 集成最新 MathJax 3 渲染引擎，完美呈现半变异函数 $\gamma(h)$、块金值 $C_0$、一阶仿射变换矩阵、布尔莎七参数、Horn 坡度算法差分方程等高级数学模型；
   - 彻底解决浏览器端公式乱码与文本错位问题。

5. **📱 全方位移动端/手机端深度响应式适配**
   - **离线滑出式章节抽屉**：手机端点击左上角 `📑` 或底部操作栏即可滑出目录；
   - **横向滑动手势筛选**：考点类型、真题筛选支持原生触摸平滑横向滚动；
   - **底部悬浮便捷操作栏**：一键切换目录、快捷搜索、开启自测、切换日间/夜间/护眼绿主题、极速回顶。

6. **🧠 考研背诵自测闪卡模式（Active Recall）**
   - 一键开启“自测遮罩”，系统自动隐藏所有答案；
   - 先在脑中回忆复述，再点击“查看考研标准答案”核对采分点，强化记忆效率。

## 🚀 GitHub Pages 在线访问部署指南

1. **推送仓库**：
   ```bash
   git init
   git add .
   git commit -m "feat: 发布地理信息系统导论专业课复习平台(中科院839专属版)"
   git branch -M main
   git remote add origin https://github.com/<你的GitHub用户名>/地理信息系统导论专业课复习平台.git
   git push -u origin main
   ```
2. **开启 GitHub Pages**：
   - 进入 GitHub 仓库页面，点击 **Settings**（设置）;
   - 在左侧菜单点击 **Pages**;
   - 在 **Build and deployment** 下方的 **Branch** 选择 `main`，目录选择 `/(root)`，点击 **Save** 保存;
   - 稍等 1-2 分钟，即可通过生成的链接在线访问：
     `https://<你的GitHub用户名>.github.io/地理信息系统导论专业课复习平台/`
